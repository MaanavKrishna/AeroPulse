API

Read-only JSON over HTTPS. No key, no sign-up. {{ settings.rate_limit }} requests a minute per address; the response headers tell you how many you have left.

Quick start

Is Delhi to Mumbai expensive for flights a week or two out?

curl {{ site_url() }}/v1/routes/DEL-BOM?window=8-14

In Python:

import httpx
r = httpx.get("{{ site_url() }}/v1/indices/national").json()
print(r["points"][-1])

In R:

library(jsonlite)
nat <- fromJSON("{{ site_url() }}/v1/indices/national?format=csv")

Endpoints

PathReturns
/v1/metaMethod version, basket, data mode (live or demo), last collection
/v1/routesEvery tracked route with today's verdict
/v1/routes/{route}One route: verdict per booking window, usual range, booking curve
/v1/indices/nationalNational index series with 95% ranges
/v1/indices/routes/{route}Route index series
/v1/indices/windows/{window}Booking-window index series
/v1/festivalsFestival calendar and tracked routes
/v1/statusCollection health per provider

Series endpoints take from, to (YYYY-MM-DD), kind (chained, the published series, or fixed, the single-basket reference) and format=csv.

Every response includes data_mode. If it says demo, the numbers are synthetic.

The complete, generated reference is at /v1/docs.

Fair use

Cache responses; the data changes a few times a day at most. For history, use the downloads. Credit "AeroPulse" with a link when you publish anything built on the data.
