# Code of conduct

AeroPulse follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise ideas rather than people, and keep
discussion on topic. Harassment of any kind is not tolerated.

Report concerns privately to the maintainers through GitHub (the repository owner's profile
lists contact options). Reports are kept confidential.
